## Sam Jones

I build governed multi-agent systems and belief-graph memory that can run on the edge. Private, auditable and on-device. Based in Barcelona.

### Open source

Multi-agent systems and models that run where your data lives.

- **[chorus](https://github.com/samjones-dev/chorus)** -> persona-seeded synthetic conversation data. A chorus of trait-seeded voices with a measured credulity dial, generated, judged, and replayed in the terminal.
- **[espigue](https://github.com/samjones-dev/espigue)** -> topic in, cited literature review out. Drives the search from the disagreements and gaps it finds; every citation and quote is mechanically verified. pip-installable, OpenRouter-backed.
- **[traitseed](https://github.com/samjones-dev/traitseed)** -> reproducible diversity for LLM data generation, seeded from curated trait lattices.
